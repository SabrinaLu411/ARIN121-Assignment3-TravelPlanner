# ARIN121-Assignment3-TravelPlanner
This travel planner is made to help users to generate a trip itinerary based on their preferences.
You will collect information such as destination, date, budget, and preferred activities from users and then generate a full itinerary.
The planner starts with showing the menu containing and asking users to name activities. After that, the planner will generate the itinerary based on the response from users. It is allowed to switch between activities. 
It can also help users to choose the destination when they are hesitant and ask the planner to help.
